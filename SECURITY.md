# Security Policy

Cortiqa takes security very seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you find a security issue:
1. Do not report via public issues.
2. Email **security@cortiqa.co** or **team@cortiqa.co**.
3. We will respond within 48 hours.
