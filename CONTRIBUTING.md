# Contributing to Cortiqa TypeScript SDK

We welcome contributions to `@cortiqa/sdk`!

---

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/cortiqa-ai/cortiqa-sdk-typescript.git
   cd cortiqa-sdk-typescript
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build the bundle:**
   ```bash
   npm run build
   ```

4. **Typecheck:**
   ```bash
   npm run typecheck
   ```

---

## Code Quality

* Format code using `npm run format`.
* Use modern TypeScript best practices without `any` wherever possible.
* Keep external dependencies to zero for the runtime library.
